# ポケスリ攻略ノート

ポケモンスリープの長期攻略用の、自分専用ノートです。スマホから閲覧と入力ができます。

- **方針**：方針の本文（Markdown）、現在のアプローチ、進行度（配下の目標から自動で集計）
- **目標（役割の枠）**：未確保 → 厳選中 → 個体確保 → 育成中 → 育成完了。完了基準は目標ごとに設定する
- **個体**：ポケモン、Lv、性格、スキルLv、食材、サブスキル、メモ。厳選中の個体はホームにメモ付きで常に表示する
- **にとよん計算機で開く**：登録した個体を、値を入力した状態で個体値計算機で開く

公開手順は [SETUP.md](SETUP.md) にあります。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面 |
| `js/app.js` | 画面の表示と操作 |
| `js/store.js` | データ保存（Firebase、未設定ならこの端末のブラウザに保存） |
| `js/firebase-config.js` | Firebase の設定 |
| `js/nitoyon.js` | 個体値計算機へのリンク生成 |
| `js/pokedex.js` | ポケモン・サブスキル・性格データ（自動生成） |
| `tools/build_pokedex.py` | `pokedex.js` の生成スクリプト（新ポケモン追加時に再実行） |
| `firestore.rules` | データのアクセスルール |
